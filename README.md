# DeepSeek Chat Reader (v2)

DeepSeek 导出对话查看器（[在线版](https://deepseek-chat-reader.github.io/)）。读取 DeepSeek 官方导出的 `conversations.json` / `converts.json`，在本地离线查看聊天记录。

> v2（`refactor-v2` 分支）为重构版本：Vite + TypeScript 多文件源码，构建为单个离线 `index.html`（全部依赖内联，无 CDN）。

## How To Use

1. 访问并登录 <a href="https://chat.deepseek.com/" title="DeepSeek">DeepSeek</a>，点击左下角头像 `...` → `系统设置`。
2. 选择 `数据管理` → `导出所有历史对话`，下载 `deepseek_data-[日期].zip`。
3. 解压后找到 `conversations.json`（旧版导出可能叫 `converts.json`）。
4. 打开 <a href="https://deepseek-chat-reader.github.io/" title="DeepSeek-Chat-Reader">DeepSeek-Chat-Reader</a>（或本地双击 `index.html`），上传该 JSON 文件即可查看。

## 支持的导出格式（2026-08 实测）

- **fragment 类型**：`REQUEST / RESPONSE / THINK / SEARCH / FILE / TOOL_SEARCH / TOOL_OPEN`
- 附件（手动上传、长文本自动转附件、识图图片）以 `FILE` fragment 存储，显示为"文件名 + 大小"块
- 新式搜索（`TOOL_SEARCH` 结果列表 + `TOOL_OPEN` 浏览标记）与老式搜索（`SEARCH`）均支持
- 引用角标：新格式 `[reference:N]`（0 起）、老格式 `[citation:N]`（1 起），均渲染为可点击的角标链接
- 分支：支持多层嵌套分支导航（同一层最多 6 个分支）
- 深度思考（THINK，可与工具调用交错出现）折叠显示；停止生成的消息按截断内容显示
- 兼容 2025-09 及更早的旧导出格式

## 功能

- 数学公式渲染（MathJax，SVG 输出，离线可用）
- Mermaid 图表渲染
- Markdown 渲染 + 代码高亮（复制 / 下载）
- 会话搜索、日期筛选、排序（开始/结束时间、标题、升降序）
- 明暗主题、中英双语
- 分支导航（多分支切换、删除分支）、会话标题编辑、会话/分支删除
- 批量选择删除、大纲侧边栏（按回复标题跳转）
- 保存：导出编辑后的 JSON、带数据快照的 HTML、纯阅读器快照

## 开发 / 构建

```bash
npm install
npm run dev      # 开发预览
npm test         # 回归测试（基于真实导出数据）
npm run build    # 构建单文件产物 -> index.html（提交到仓库，GitHub Pages 直接使用）
```

### 结构

```
index.html            # 构建产物（部署用）
src/
  app.html            # 应用壳（Vite 入口）
  main.ts             # 入口与装配
  types.ts            # 导出格式类型
  parser.ts           # JSON -> 内部模型（新旧格式归一化）
  model.ts            # 会话树遍历 / 分支
  citation.ts         # [reference:N] / [citation:N] 解析
  render/             # markdown / math / mermaid / message
  ui/                 # sidebar / detail / theme
  i18n.ts  storage.ts
  styles/             # main.css / print.css
tests/                # vitest 回归（用真实 conversations.json）
```
